# 安全问题 · Security

## 简体中文

如果你发现光渡可能导致素材损坏、校验结果失真、数据外泄或安装包被篡改的问题，请**不要在公开 Issue 里描述细节**，改发邮件到 [support@lightferry.app](mailto:support@lightferry.app)，标题注明「安全」。

请尽量附上：光渡版本、macOS 版本与 Mac 芯片、复现步骤、影响范围，以及你观察到的现象。不要附带原始素材、客户资料或激活码。我们会在确认后回复，并在修复版本的发布说明里注明。

只为最新公开版本提供安全修复，请先升级到 [最新版本](https://github.com/Sorasukiawa/lightferry/releases/latest) 再确认问题是否仍然存在。安装包只从本仓库 Releases 发布；从其他渠道获得的安装包请勿使用。

## English

If you find an issue that could corrupt media, misreport verification, leak data, or tamper with installers, please **do not post details in a public issue**. Email [support@lightferry.app](mailto:support@lightferry.app) with "Security" in the subject.

Include the Lightferry version, macOS version and Mac chip, reproduction steps, impact, and what you observed. Do not attach original media, client information, or license keys. We will reply once we confirm the report and credit the fix in the release notes.

Security fixes are provided for the latest public release only. Please update to the [latest release](https://github.com/Sorasukiawa/lightferry/releases/latest) and check whether the issue persists. Installers are published only in this repository's Releases; do not use installers from any other source.
